<threat_model>
## Assets

- Companion API key, household GTIN/product data, provider URLs/tokens, trace identifiers, service availability.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Grocy → companion | Authenticated owned request and trace enter companion. |
| Companion → external providers | Untrusted third parties receive provider queries but must not receive owned trace/credentials. |
| Provider response → diagnostic envelope | Untrusted failures/payloads are reduced to closed enums/timings. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-04-01 | Information Disclosure | Diagnostic DTO | mitigate | Closed field constructors and forbidden-canary tests; exclude GTIN/URLs/headers/keys/payloads/tokens/exceptions. |
| T-01-04-02 | Spoofing/Tampering | `traceparent` | mitigate | Strict v00 validation, reject zero IDs, replace invalid input, new parent ID. |
| T-01-04-03 | Information Disclosure | Provider requests | mitigate | Terminate W3C propagation at companion; assert no trace or Grocy credentials in external headers. |
| T-01-04-04 | Denial of Service | Provider calls | mitigate | One 10.5s outer deadline, 2s connect/6s read, remaining-budget checks, no automatic retry. |
| T-01-04-05 | Repudiation | Failure classification | mitigate | Finite stage/outcome enums and wall-clock durations distinguish not-found from error/timeout. |

## Residual Risks

- Third-party availability remains external; deterministic tests and named outcomes transfer, rather than eliminate, that risk.
</threat_model>
