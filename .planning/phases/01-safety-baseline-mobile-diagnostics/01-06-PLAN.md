<threat_model>
## Assets

- Current user intent, preview integrity, form/file state, diagnostics, browser availability, persistence boundary.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Async callback → current DOM | Late/untrusted response competes for UI ownership. |
| Server diagnostic → copy/console | Safe server DTO is still treated as untrusted input. |
| Browser lifecycle/network events → request state | Background/back/reconnect can trigger races or amplification. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-06-01 | Tampering | Stale response | mitigate | Monotonic token + normalized-GTIN check on every callback; invalidate before abort. |
| T-01-06-02 | Denial of Service | Duplicate/retry behavior | mitigate | Same-intent coalescing, one active XHR, explicit Retry only, fixed deadline. |
| T-01-06-03 | Information Disclosure | Diagnostic copy/DOM/console | mitigate | Second closed allowlist, textContent, canary tests, no raw object serialization. |
| T-01-06-04 | Information Disclosure | Raw exception | mitigate | Finite safe outcome mapping and exact fixed localized copy only. |
| T-01-06-05 | Tampering/Repudiation | Hidden write/form clearing | mitigate | Zero-write counters and preservation tests across every terminal state. |

## Residual Risks

- Browser `navigator.onLine` is only a coarse classification hint; transport outcome and copied report label uncertainty rather than claiming reachability.
