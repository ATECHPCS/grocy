<threat_model>
## Assets

- User product-form values, selected file, authenticated session, GTIN intent, and persistence boundary.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Camera/manual input → browser | Untrusted GTIN enters validation and request construction. |
| Browser → authenticated Grocy API | Valid intent crosses same-origin auth boundary. |
| Response → preview/form staging | Untrusted suggestion data can affect DOM or staged form fields. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-03-01 | Tampering | GTIN input | mitigate | String-only normalization, GS1 checksum, supported lengths, encoded path, mirrored server validation later. |
| T-01-03-02 | Information Disclosure | Raw error/rendering | mitigate | Fixed safe state copy and textContent rendering; no raw response/exception display. |
| T-01-03-03 | Denial of Service | Repeated search | mitigate | One active XHR handle, disabled Search for current intent, exact browser deadline; full coalescing in Plan 01-06. |
| T-01-03-04 | Tampering | Hidden writes | mitigate | No write verbs/endpoints; negative route counters; normal Save code untouched. |

## Residual Risks

- Full stale-response and duplicate race handling is completed and tested in Plan 01-06; this slice is sequenced before it but never adds persistence.
