<threat_model>
## Assets

- Grocy session/permission boundary, companion API key, diagnostic integrity, user preview/form state.

## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser → Grocy controller | Untrusted route parameter/header enters authenticated service. |
| Grocy → companion | API key and validated owned trace leave Grocy. |
| Companion response → browser | Untrusted JSON becomes safe preview/diagnostic envelope. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-01-05-01 | Information Disclosure | Error/diagnostic response | mitigate | Closed DTO, fixed error enums, no raw exceptions/headers/URLs/keys/payloads/GTIN. |
| T-01-05-02 | Spoofing/Tampering | Inbound trace | mitigate | Strict parser, zero-ID rejection, secure replacement/new parent ID. |
| T-01-05-03 | Denial of Service | Guzzle request | mitigate | 12s total, 2s connect, redirects false, no automatic retry. |
| T-01-05-04 | Elevation of Privilege | Enrichment routes | mitigate | Existing authentication middleware and permission-first `MASTER_DATA_EDIT`. |
| T-01-05-05 | Tampering/Repudiation | Hidden persistence | mitigate | GET-only routes, no DB dependency, negative source/test assertions, normal Save remains sole writer. |

## Residual Risks

- `Server-Timing` is browser-visible to the authenticated caller; metric names and durations are intentionally coarse and contain no identifiers.
