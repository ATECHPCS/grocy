## Phase Goal

**As a** household maintainer, **I want to** know that a bulk apply can only run a fixed, named set of vetted operations, **so that** the engine can never be coerced into arbitrary CRUD or SQL by the browser or companion.

<objective>
Enforce a closed named-typed-operation registry: only `assign_taxonomy_leaf` and `set_unclassified` resolve, each delegating to the shipped `AssignProductTaxonomy` write, and every other operation fails closed with one bounded blocker.

Purpose: guarantee the engine is a curated dispatcher over existing vetted writes, never a parallel or arbitrary write path.
Output: a registry and resolver in `GrocyAiBulkService` that binds the two proving operations to the shipped taxonomy write and rejects free-form entity/field/CRUD/SQL before any write.
</objective>
