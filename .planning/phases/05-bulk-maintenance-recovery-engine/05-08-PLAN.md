## Phase Goal

**As a** household maintainer, **I want to** have an immutable record of who previewed and applied a plan and exactly what each item changed, **so that** the result is auditable and recoverable even if I skipped a database backup.

<objective>
Deliver the append-only audit ledger: every apply appends, inside the same transaction as its mutations, one immutable record per item and event capturing the session-user actor, previewed/applied timestamps, module/version, per-item outcome, and exact before/after values — reconstructable and never mutable.

Purpose: make the audit trail a first-class safety artifact (data safety must hold without a DB backup), modeled on the append-only conversion activation evidence ledger.
Output: the `grocy_ai_bulk_audit` schema, the in-transaction audit appends, a read endpoint for reconstruction, and the append-only / same-transaction / exact-values tests.
</objective>

<threat_model>
## Trust Boundaries
| Boundary | Description |
|---|---|
| apply mutation → audit record | The record of what changed must be atomic with the change itself. |
| session identity → actor field | The audited actor must be the authenticated session user, not a browser claim. |
| stored audit → later reads/edits | An audit row must be immutable once written. |
## STRIDE Threat Register
| Threat ID | Category | Component | Disposition | Mitigation Plan |
|---|---|---|---|---|
| T-05-08-01 | Repudiation | audit trail | mitigate | Append one immutable row per item/event with actor, previewed/applied timestamps, version, outcome, exact before/after. |
| T-05-08-02 | Tampering | audit mutability | mitigate | INSERT-only ledger; no UPDATE/DELETE/REPLACE path in service or migration; source-grep assertion. |
| T-05-08-03 | Spoofing | actor identity | mitigate | Actor is the session user passed from the authenticated apply endpoint, never a request-body field. |
| T-05-08-04 | Tampering | orphaned audit on failure | mitigate | Audit INSERTs occur inside the apply transaction, before commit, so rollback discards them. |
| T-05-08-SC | Tampering | package installs | accept | No package installation is planned. |
</threat_model>
