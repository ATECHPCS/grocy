## Phase Goal

**As a** household maintainer, **I want to** preview an audited bulk apply's reversal and see exactly which items can be safely undone, **so that** I can recover from a mistaken apply without ever clobbering an edit I made by hand afterwards.

<objective>
Deliver a guarded recovery slice: a zero-write rollback preview computed from the immutable audit ledger, and a rollback execution that runs through the identical named-operation, conflict-safe, single-transaction, idempotent path as forward apply.

Purpose: make the audit trail actionable for recovery without turning it into a blind overwrite tool.
Output: `PreviewRollback` plus a rollback-apply delegate on `GrocyAiBulkService`, with a read-only preview surface.
</objective>
