## Objective
Fix the real data gap: 214 ungrouped products (~49%) that starve the classification scorer of its primary evidence. A reviewed bulk pass suggests a product group for each ungrouped in-scope product, applied/rolled back through the hardened Phase 5 engine.

## Integration reality (verified 2026-09-08)
`ApplyPlan` currently decodes `proposed['leaf_slug']` and calls `delegate(objectId, leafSlug)` — it is leaf-slug-specific. `suggest_product_group`'s proposed value is a group id, so the delegate dispatch must be generalized to pass the decoded proposed payload. This is a small, surgical change; taxonomy apply/rollback MUST remain byte-identical (regression test required). This corrects the DESIGN's optimistic "no engine changes" for this one operation.
