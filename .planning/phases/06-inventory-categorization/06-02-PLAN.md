## Objective
Build the DATA-06 zero-diff proof and the DATA-07 rollback/idempotency rehearsal on top of the *existing* bulk engine — which already stores before/after images in `grocy_ai_bulk_audit` and supports `PreviewRollback`/`RollbackPlan`. No new rollback storage; this plan proves and drives what exists.

## Reuse facts (verified)
`ApplyPlan` runs a single `BEGIN IMMEDIATE`, records `before_image_json`/after into `grocy_ai_bulk_audit`, stamps `applied_at`, and is idempotent (an already-applied item for the same checksum is skipped). `RollbackPlan`/`PreviewRollback` restore from the stored before-images. So the "pre-apply snapshot" (Q10) already exists as the audited before-image; this plan verifies it, it does not re-implement it.
