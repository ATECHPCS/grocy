## Objective
Build the production-shaped local snapshot that gates every later Phase 6 plan (profiling, DATA-06 checksum, DATA-07 rollback rehearsal). Real prod data (434 products, 214 ungrouped, 62 global conversions) with secrets stripped, re-runnable, never committable.

## Access reality (verified 2026-09-08)
Direct SSH to the DB host `10.10.0.156` has no key. The SQLite lives at `/etc/komodo/grocy` mounted into the Grocy container, managed by the Komodo host `10.10.0.162` (alias `DockerKomodo`). The refresh path is therefore: reach the Komodo host → `docker cp` the DB out of the Grocy container (or copy the mounted volume file) → transfer locally → scrub. Task 1 pins the exact command that works before any scrub logic is written.
