## Trust Boundaries

| Boundary | Description |
|---|---|
| rehearsal commands → live prod | Any mutating rehearsal step must target the snapshot copy, never the live `/etc/komodo/grocy` volume or DB. |
| backup file → restored DB | The restore must preserve integrity and the exact 444-product shape or the rollback is not trustworthy. |
| prior-image tag → redeploy artifact | A mutable tag can be overwritten by the cutover; only the pinned digest is a safe rollback target. |
