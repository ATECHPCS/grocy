## Trust Boundaries

| Boundary | Description |
|---|---|
| Barcode text → canonical ownership query | Untrusted text must retain leading zeroes and pass GS1 validation. |
| Database owner → browser navigation | Only a trusted local integer ID may control the route. |
| Review state → persistence | `Ready to add on Save` is transient and must not insert. |
| Media handle → upstream network | Phase-wide secure-media invariants remain mandatory before media use. |

## Phase-Wide Security Invariants

All Grocy module routes are authenticated same-origin and require `MASTER_DATA_EDIT` before guarded work. Media handles are opaque random, 15-minute, 512-entry, variant-bound capabilities and raw URLs are never browser-visible. Each upstream URL and at most two redirects is structurally parsed, DNS/IP revalidated, and denied for private/link-local/loopback/multicast/unspecified/reserved/metadata IPv4/IPv6 or HTTPS downgrade. Fetch limits are 2-second connect, 12-second total, streamed 2,000–3,000,000 bytes, JPEG/PNG/WebP MIME and magic, decoded 32–4096 dimensions, and 16MP. Secrets, URLs, tokens, payloads, headers, exceptions, household values, and full barcodes are redacted. Every non-Save path is zero-write.
