## Trust Boundaries

| Boundary | Description |
|---|---|
| Browser preflight → concurrent database | Check-then-insert races require an atomic uniqueness invariant. |
| Product Save result → barcode continuation | A trusted product ID must be retained without replaying product creation. |
| Migration → household data | Existing collision rows must block, never be auto-deleted/reassigned. |
| Media handle → upstream network | Phase-wide secure-media controls remain mandatory for later media activation. |

## Phase-Wide Security Invariants

Authenticated same-origin routes check `MASTER_DATA_EDIT`. Media handles remain cryptographically random, 15-minute, 512-entry, variant-bound, and absent from browser-visible raw URLs/logs. Upstream media URLs and each of at most two redirects require structural parse and fresh DNS/IP denial of private/link-local/loopback/multicast/unspecified/reserved/metadata IPv4/IPv6, with no HTTPS downgrade. Connections use a 2-second connect limit and 12-second total limit; streaming enforces 2,000–3,000,000 bytes, JPEG/PNG/WebP MIME plus magic, decoded 32–4096 dimensions, and 16MP. Secrets/tokens/URLs/headers/payloads/exceptions/household values/full barcodes are redacted. Search, preview, cancel, timeout, stale, malformed, media, navigation, and local staging paths are zero-write.
