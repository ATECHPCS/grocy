## Trust Boundaries

| Boundary | Description |
|---|---|
| Recorded SHA → built/running image | Build drift or mutable tags can run unreviewed code. |
| Container replacement → persistent household data | Mount/schema errors can lose or mutate inventory. |
| Smoke credential → logs/evidence | Existing auth must stay process-local and redacted. |
| Deployed media routes → network/files | Production must retain every SSRF/timeout/content/handle gate. |

## Phase-Wide Security Invariants

Running services must enforce authenticated same-origin session/API-key authorization before work; opaque random 900-second/512-entry variant-bound handles; no external URL exposure; per-hop URL/DNS/IP/actual-peer denial of private/link-local/loopback/multicast/unspecified/reserved/metadata IPv4/IPv6; two redirects/no downgrade; 2-second connect/12-second total; streamed 2KB–3MB; exact JPEG/PNG/WebP MIME+magic; decoded 32–4096/16MP; secret/token/URL/header/payload/exception/household/full-barcode redaction; and zero writes on all non-Save flows.
