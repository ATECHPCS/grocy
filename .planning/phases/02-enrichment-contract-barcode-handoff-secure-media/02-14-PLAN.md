## Trust Boundaries

| Boundary | Description |
|---|---|
| Household test data → evidence/chat | Real values must stay private and process/browser-local. |
| Human Save → durable product/barcode/file state | Only the reviewed reversible diff may persist and it must be restored. |
| Real media interaction → browser/network | Same-origin capability controls must remain intact outside deterministic fixtures. |
| Phase 2 evidence → Phase 1 status | New evidence cannot falsify the skipped earlier physical gate. |

## Phase-Wide Security Invariants

The deployed flow retains authenticated same-origin permission checks; opaque random 900-second/512-entry variant-bound handles; no external URL disclosure; full per-hop URL/DNS/IP/actual-peer denial for private/link-local/loopback/multicast/unspecified/reserved/metadata IPv4/IPv6; maximum two redirects/no downgrade; 2-second connect/12-second total; streamed 2KB–3MB; exact JPEG/PNG/WebP MIME+magic; decoded 32–4096/16MP; secret/token/URL/header/payload/exception/household/full-barcode redaction; and zero writes on every non-Save path.
