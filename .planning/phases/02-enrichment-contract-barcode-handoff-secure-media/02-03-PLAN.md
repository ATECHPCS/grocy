## Trust Boundaries

| Boundary | Description |
|---|---|
| Validated DTO → selector/DOM | Companion values must never become arbitrary selectors, HTML, or active local IDs. |
| Transient review state → native controls | Staging must affect only selected, still-current rows and never call persistence. |
| User edit → stale suggestion | A live manual edit supersedes the captured response. |
| Media handle → upstream network | Later media work remains constrained by the phase-wide invariants below. |

## Phase-Wide Security Invariants

All module routes are authenticated same-origin and permission-first. Opaque media handles remain random, 15-minute, 512-entry-bounded, variant-bound, and absent from logs; browser-visible external URLs are forbidden. Every media URL and each of at most two redirects must be re-parsed and re-resolved, denying private/link-local/loopback/multicast/unspecified/reserved/metadata IPv4/IPv6 targets and HTTPS downgrade. Fetching retains 2-second connect, 12-second total, 2,000–3,000,000 streamed-byte bounds, exact JPEG/PNG/WebP MIME plus signature checks, decoded dimensions 32–4096, and 16MP maximum. Secrets, URLs, tokens, headers, payloads, exceptions, household values, and full barcodes are excluded from telemetry. Search/review/diff/staging/cancel/timeout/stale/media/navigation paths write nothing durably.
