## Trust Boundaries

| Boundary | Description |
|---|---|
| Candidate URL/DNS → actual peer | Attacker can redirect/rebind toward internal services. |
| Stream → memory/decoder | Length/content/dimensions are untrusted. |
| Capability → media bytes | Guessing/replay/variant confusion must fail. |
| Grocy response → browser/native File | Auth, second validation, and transient staging are required. |

| T-02-07-01 | Spoofing/Information Disclosure | SSRF | mitigate | Per-hop URL/DNS plus actual-peer binding; proxies off. |
| T-02-07-02 | Denial of Service | Stream/decoder | mitigate | Exact deadlines, incremental cap, type/signature/dimension/pixel gates. |
| T-02-07-03 | Information Disclosure | Handle/origin | mitigate | Random bounded variant handles; no URL/token visible or logged. |
| T-02-07-04 | Elevation of Privilege | Routes | mitigate | API key/session/permission before work. |
| T-02-07-05 | Supply-chain Tampering | Companion build | mitigate | Exact constraints and installed-set hash. |
| T-02-07-06 | Tampering | File persistence | mitigate | Reducer-only File until explicit stage; normal Save only. |
</threat_model>
